# План эксперимента: Оптимизация промптов для Information Extraction с помощью GEPA

## 1. Цель эксперимента
Исследовать эффективность применения фреймворка **GEPA (Genetic-Pareto Prompt Evolution)** для автоматического улучшения промптов при решении задачи извлечения информации (Information Extraction) с использованием локальной LLM (Qwen 3.5 - 2B).

## 2. Постановка задачи (Scope)
На первом этапе фокусируемся на **Задаче NER (Named Entity Recognition)**:
*   **Вход:** Текст из предметной области "Компьютерная лингвистика".
*   **Выход:** Структурированный список извлеченных терминов и их классов (например: "Transformer (Model), Attention (Method)").
*   **Данные:** `ents/doc/articles_dataset.json`. Разделение: `train.jsonl` (для GEPA) и `test.jsonl` (для оценки).

## 3. Технологический стек и инструменты
*   **LLM (Target):** Локальная модель Qwen 3.5 - 2B (запущена через Ollama как `my-qwen`).
*   **API:** Ollama API (`http://localhost:11434`).
*   **Фреймворк оптимизации:** `GEPA` (локальный репозиторий в `./gepa`).
*   **Метрика:** Recall (Полнота) — процент найденных терминов из эталонной разметки.
