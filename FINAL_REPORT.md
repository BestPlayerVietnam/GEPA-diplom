## 2. Что нужно сделать (План на завтра на мощном железе)

### Шаг 1: Восстановление окружения
1.  Установить библиотеки: `pip install requests litellm pydantic json_repair`.
2.  Загрузить модель в Ollama (либо через `ollama create` с твоим Modelfile, либо просто `ollama pull qwen2.5:1.5b` для скорости).

### Шаг 2: Запуск Baseline (Точка отсчета)
1.  Запустить `python baseline.py`.
2.  Зафиксировать значение Recall (оно покажет, сколько сущностей модель находит с простым промптом).

### Шаг 3: Настройка и запуск GEPA
1.  Создать файл `run_gepa.py` (я подготовлю его структуру ниже).
2.  Подключить GEPA к Ollama (через LiteLLM).
3.  Запустить процесс оптимизации:
    *   GEPA будет прогонять `train.jsonl`.
    *   Анализировать ошибки через "Reflection" (объяснять, почему модель пропустила термин).
    *   Мутировать промпт, добавляя в него уточняющие правила.
4.  Получить "Best Prompt" по итогам 10-20 поколений.

### Шаг 4: Итоговая оценка
1.  Обновить `baseline.py`, вставив туда лучший промпт от GEPA.
2.  Замерить Recall на `test.jsonl`.
3.  Сравнить результат: `Baseline Recall` vs `GEPA Optimized Recall`.
